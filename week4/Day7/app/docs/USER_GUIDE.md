# User Guide — Ayesha Voice Agent

## What Ayesha Can Do

- Answer property questions in UrduLish
- Recommend properties by city, budget, bedrooms, purpose
- Handle price/trust/location/investment objections
- Book, reschedule, cancel property visits
- Send email notifications to assigned agents

## Sample Conversations

### Example 1 — Buyer inquiry
> **Caller:** Assalam o Alaikum
> **Ayesha:** Wa Alaikum Assalam! RealEstate Hub se baat ho rahi hai, main Ayesha. Aap ki kis tarah madad kar sakti hoon?
>
> **Caller:** Lahore DHA mein 3 bedroom chahiye, 3 crore tak
> **Ayesha:** Ji sir, yeh options hain: property_id 13753525 (5 Marla, 1.5 cr), ...

### Example 2 — Objection
> **Caller:** Yeh mehnga hai
> **Ayesha:** Main samajh sakti hoon budget important hai — is se milta julta ek option hai jo thora kam mein aa jayega...

### Example 3 — Booking
> **Caller:** Visit book kar dein
> **Ayesha:** Zaroor! Aapka visit 2026-10-10 11:00 baje ke liye book ho gaya hai, appointment ID abc123.

## Tips

- Speak clearly — Deepgram handles UrduLish well but not extreme code-switching mid-word
- Mention budget in "crore" or "lakh" for best results
- Mention city explicitly (Lahore / Karachi / Islamabad / Rawalpindi / Faisalabad)
- Say "cancel" or "reschedule" for appointment management
